# ポモドーロ & タスク

シンプルなポモドーロタイマーとタスクリストを組み合わせた、単一HTMLファイルの生産性ツールです。

## 特徴

- 🍅 作業25分 / 休憩5分（4サイクルごとに15分の長い休憩）。時間になると音が鳴って次のフェーズに切り替わり、タイマーは止まる。次を始めるときは「開始」を押す
- ✅ タスクの追加・完了チェック・削除
- 🎯 タスクをクリックして「取り組み中」に設定すると、完了したポモドーロ数を自動記録
- 💾 `localStorage` でブラウザを閉じても状態を保持
- 🔔 フェーズ終了時にサウンドで通知

## 使い方

公開ページ：https://sokken21.github.io/pomodoro-tasks/ （GitHub Pages）

`index.html` をブラウザで開くだけで動作します。ビルドや依存関係のインストールは不要です。

```bash
# ローカルで開く場合
start index.html   # Windows
open index.html     # macOS
```
